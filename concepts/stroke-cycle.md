# Stroke cycle

## Key takeaway

Define the events and counting convention before comparing strokes.

## Summary

A stroke cycle is a repeated pattern of limb and body actions. A breaststroke cycle normally includes one paired arm cycle and leg cycle; front-crawl counting may mean one arm entry or a complete left–right pair. The chosen convention must be explicit.

## Definition and use

One repetition of the chosen reference events in a stroke.

Name event markers such as hand extension, onset of inward action, foot preparation and kick completion. Those markers make timing comparable without requiring constant durations.

## Boundary and non example

An event sketch is not a universal race technique or an exact phase-timing prescription. Pace and task can change the overlap among events.
