# Reference records

## Key takeaway
A local Reference identifies an external publication and exactly what it contributes; it is not the source itself or proof of its claims.

## Summary
Only Markdown records are stored here. A record includes publication identity, date basis, external address, inspected extent, located claims, evidence lineage and nonclaims. Naming uses creator, publication year when known, and a concise title. An access year never masquerades as publication year. Several records may describe one evidence family or implementation chain.

## How to use a record
Read the local Summary and claim contribution, then examine the scope and what the source does not establish. A claim-specific locator tells you where to inspect the external source. If only an abstract was accessible, do not infer full methods, raw data or unreported outcomes. Place your own synthesis in the relevant knowledge file rather than rewriting the publication's contribution.

## Inspection scope and history

Each publication record owns its access date, inspected extent, claim locators, source family and limitations. Access notes inherited from the Swim 4.0.0 reconstruction remain historical; packaging release 4.0.1 did not itself add a literature inspection. Any later recheck must state its own date and extent. This documentation consolidation performs no new source inspection.

The retained synthesis reports no raw-data or statistical reanalysis, comprehensive systematic search, independent expert review or real-user effectiveness trial. Several records from one organization or handbook are not independent replications. KPS organisation and the source-synthesis Method are authored designs, not empirically established optima.

The [passive-drag record](cortesi-2015-head-position-and-passive-drag.md) retains its blocked recheck and inherited extraction. The [breaststroke kinematics record](gourgoulis-2022-breaststroke-arm-kinematics.md) retains bibliographic-only recheck access and an earlier abstract extraction. Neither becomes a fresh full-text inspection because it is linked here. For every source, compare the recorded population, task and access limits with the intended claim.

Read [Source synthesis](../docs/SOURCE-SYNTHESIS.md) for disagreements and selected interpretations. Official documentation describes an interface; it does not establish KPS learning effectiveness. Only publication records are bundled, not external source copies.
