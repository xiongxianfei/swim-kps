# AI and agent contribution instructions

## Key takeaway
AI-generated Swim KPS changes must conform to the KPS Core authoring contract and undergo a separate swimming-safety and evidence review.

## Summary
AI-generated Swim KPS changes must conform to the KPS Core authoring contract and undergo a separate swimming-safety and evidence review.

## Required workflow
1. Read [Core AUTHORING.md](https://github.com/xiongxianfei/knowledge-practice-system/blob/8fd410d1a8dec8b3e38352c9166639906049ec55/AUTHORING.md) and local [Swim authoring](AUTHORING.md).
2. Select the right Concept, Principle, Model, Method or Practice role; References are provenance records, not an extra knowledge role.
3. Preserve complete human-readable summaries, safe procedures, scoped statements and actual heading-derived links. Stage numbering is recommended order, not identity or dependency.
4. Do not synthesize fake session results, diagnose pain, prescribe breath restriction or present a swimming cue as universal law.
5. Cite actual inspected evidence, indicate uninspected/full-text limits, consider alternatives, and do not borrow copyrighted figures or extensive publication text.
6. Run `python3 validate.py .` and `python3 test_validate.py`. Ensure safety-, evidence- and human-experience-related changes receive meaningful human review.
