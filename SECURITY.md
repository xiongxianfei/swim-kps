# Safety and security reporting

## Key takeaway
For immediate water safety problems, stop the activity and seek in-person help; repository discussions are not emergency response or medical triage.

## Summary
For immediate water safety problems, stop the activity and seek in-person help; repository discussions are not emergency response or medical triage.

## Physical safety content concerns
If a published Method or Practice appears to encourage unsafe breath restriction, unsupported water skills, pain or a difficult return to air, raise the concern through a public issue only if the report can be made safely without personal identifiers. Do not reproduce the allegedly unsafe activity to demonstrate it. Urgent or individualized risks need appropriate real-world assistance.

## Software security reports
This repository also contains a Python validator and GitHub workflow. Before public launch, the maintainer should enable a confidential vulnerability-reporting route or provide a contact; do not post exploit details, personal identifiers or secrets in public issues.
