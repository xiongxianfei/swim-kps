# Keeping personal swimming records private

## Key takeaway
General knowledge belongs in the public repository; identifiable observations, medical details and private session history belong elsewhere by default.

## Summary
General knowledge belongs in the public repository; identifiable observations, medical details and private session history belong elsewhere by default.

## Separation boundary
Public: reusable definitions, explanatory relationships, mechanisms, bounded and safe trials, complete self-coaching Practices, reference records and **blank** templates. Private: dated sessions, personal sensations, videos, observer identities, medical information, performance history, contact details and permission-restricted media.

## How to reuse private learning safely
Use the [blank session template](SESSION-TEMPLATE.md) in a separate private folder or private repository—not within this public Git tree. If an observation suggests a reusable improvement, abstract it into a question and hypothesis, remove identifying context, consult independent supporting evidence, and submit the bounded claim without publishing the original record. Permission is needed for another person's information or likeness.

## Public examples
If later included, label invented examples as **fictional**, independent case reports as **individual observations**, and tentative mechanisms as **hypotheses**. Do not fabricate successful swim sessions or infer ability from a template.
