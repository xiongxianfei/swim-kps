# Breaststroke cycle model

## Key takeaway

Relate arm action, kick, air access and return to length so that a reference movement can be understood and checked.

## Summary

Watch a complete cycle and label the arm inward action, inhalation opportunity, arm return, heel recovery, main kick and return to length. Some events overlap. The sketch locates timing questions; it does not prescribe four pauses.

## Local explanatory basis

Changing limb orientation and motion can change the direction and useful contribution of the interaction with water. A recovery movement changes both the readiness of the limb for the next action and the swimmer’s interaction with water. The effects of component movements depend partly on their timing relative to other movements and the breathing opportunity.

## Purpose
Relate arm action, kick, air access and return to length so that a reference movement can be understood and checked.

## Representation
The phases below are reference events, not fixed-duration compartments.

| Event | Candidate movement reference | Main observation |
|---|---|---|
| Preparation | Hands separate from forward extension; forearms reorganize | Direction/extent and comfortable elbow motion |
| Inward action and air opportunity | Hands/forearms move inward; torso/shoulder rise and breath coordinate | Mouth clearance and timing, not a forced neck lift |
| Forward recovery and leg preparation | Hands return ahead while the legs recover/prepare | Whether one event stalls the other |
| Effective kick and completion | Prepared feet act through the water and legs return toward length | Preparation, completion and usable body line |
| Continuity into the next cycle | A brief recognizable return followed by the next chosen action | Neither interrupted completion nor an excessive wait |

A low-demand starting reference puts the arms approaching extension as the effective kick occurs. Recovery events may overlap; the model does not demand perfectly stationary legs throughout the pull. The common pull/breathe/kick/glide cue is a memory grouping, not four holds or evidence of a universal arm–leg phase relationship.

## Assumptions
Normal surface breaststroke, not the long underwater pullout after a racing start or turn. Timing varies with task and person.

## Implications
Observe event order before choosing a cue. Compactness, useful hand orientation and comfortable breathing are competing demands to integrate, not independent guarantees of speed.

## Limits
No exact elbow angle, hand depth, pull width or duration is established for the user. Downward hand pitch during preparation is not the same as excessive whole-arm pressing.

## Local evidence summary


[Improving your breaststroke technique](../references/swim-england-2018-improving-breaststroke-technique.md#surface-arm-preparation-and-recovery) contributes: The surface arm reference proceeds from extension through outward preparation and an inward action to forward recovery; it discourages an excessive sweep.

[Tips for getting breaststroke right](../references/swim-england-2016-tips-for-getting-breaststroke-right.md#basic-breaststroke-sequence) contributes: The beginner guidance groups the stroke using pull, breathe, kick and glide, returning to a stretched position.

[Breaststroke Pull: The Complete Guide](../references/us-masters-swimming-undated-breaststroke-pull.md#preparation-pulling-and-recovery) contributes: The guide separates preparation, useful pulling and forward recovery, and discusses the recovery cost of pulling too far back.
