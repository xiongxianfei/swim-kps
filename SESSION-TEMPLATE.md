# Actual swimming session blank template

## Key takeaway

A blank record contains no evidence until a real session fills it.

## Summary

Use this template to distinguish the question, predicted effect, actual observation and interpretation. There is no requirement to write a report after every swim; retain a record when it changes understanding or the next action.

Copy only when there is real experience to record. Do not treat these empty fields as evidence. Keep the note private unless deliberately shared.
