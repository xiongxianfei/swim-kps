# Swim KPS governance

## Key takeaway
Public contributions improve the knowledge base through evidence and safety review; maintainers decide when a change is ready for publication.

## Summary
Public contributions improve the knowledge base through evidence and safety review; maintainers decide when a change is ready for publication.

## Current governance
The repository owner is the initial maintainer. Contributors can open issues and pull requests. Maintainers review proposed changes and explain material objections when practical. An accepted contribution is an improvement to a bounded claim or operation, not an endorsement of the contributor's abilities or personal experiences.

## Safety sensitive review
Changes affecting air access, breath control, water depth, unsupported skills, pain or injury must describe their stop condition and intended population. Structural validation is necessary but insufficient; unverified physical claims remain qualified or excluded.

## Compatibility and release decisions
Swim versions evolve independently from [KPS Core](https://github.com/xiongxianfei/knowledge-practice-system). This repository declares KPS language `9.x` and retains the [compatibility statement](COMPATIBILITY.md). Breaking changes to meaning or stage semantics require explicit review before release.
